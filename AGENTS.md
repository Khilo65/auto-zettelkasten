# Source-worker model preference

Use the latest verified cheapest compatible OpenAI GPT model for Codex source
workers. The current default is `gpt-6-luna` (verified October 7, 2026).

For each future upgrade, check official pricing and model guidance, the local
Codex capability catalog, request admission, source contracts, and replay tests.
Update the source default after those checks pass. Keep literature-model roles
separate. Preserve explicit model pins and historical manifests; keep a running
or resumed job pinned to its recorded model and execution identity.
